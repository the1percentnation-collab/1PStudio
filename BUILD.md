# 1P Studio — Build Overview

**1P Studio** is an AI-powered TikTok content generator built for **The One Percent Nation**, the self-help and leadership coaching brand of creator **Anthony Brown**. You drop in TikTok videos and the app returns a full, brand-tuned content strategy for each one — titles, on-screen hooks, captions, hashtags, a scored hook rating, and more — generated by Anthropic's Claude.

---

## What it does

1. **Upload** up to 20 TikTok video files by drag-and-drop (or click to browse).
2. In the **browser**, the app extracts three still frames from each video — a hook frame (~4%), a mid frame (~45%), and an end frame (~85%).
3. The frames (plus an optional transcript and the filename) are sent to a backend endpoint that calls **Claude** with a strategist system prompt tailored to the brand's voice and content pillars.
4. Claude returns a structured JSON content package per video, rendered as a **content card** with copy, regenerate, and remove actions.
5. Results are cached in a local **Library** tab, and all cards can be exported to **CSV**.

### Generated fields (per video)

| Field | Purpose |
|-------|---------|
| `best_title` | Strongest search/click-optimized title (≤70 chars) |
| `titles` | 3 alternate title angles |
| `on_screen_text` | Stop-scroll overlay hook (≤8 words, caps) |
| `thumbnail_text` | High-contrast thumbnail copy (≤6 words) |
| `headline` | All-caps TikTok-search headline (≤60 chars) |
| `seo_opener` | First-3-seconds hook line |
| `caption` | Full caption with hook, body, soft CTA (150–300 chars) |
| `video_description` | Full description (200–400 chars) |
| `hashtags` | 12–15 mixed niche/broad/trending tags |
| `niche` | Specific content niche (2–4 words) |
| `content_pillar` | One of the brand's four pillars |
| `hook_score` + `hook_score_reason` | 1–10 hook rating with an improvement tip |
| `transcript_summary` | 1–2 sentence summary of the video |

The brand voice, content pillars, and field rules all live in the `SYSTEM_PROMPT` in `functions/src/index.ts`.

## Architecture

```
Browser (React SPA)                    Firebase
┌─────────────────────────┐            ┌──────────────────────────────┐
│ DropZone → extract 3     │  POST      │ Hosting                      │
│ frames (canvas)          │  /api/     │  rewrite /api/analyze →      │
│ claudeService.js         │──analyze──▶│  Cloud Function analyzeVideo │
│ VideoCard / LibraryView  │◀──JSON─────│   → calls Anthropic Messages │
│ localStorage library     │            │      API (Claude)            │
└─────────────────────────┘            └──────────────────────────────┘
```

- **Frontend** — a React 18 single-page app scaffolded with **Create React App** (`react-scripts`). Entry point `src/App.js`; all styling is inline CSS-in-JS (no UI library). Frame extraction is done client-side via a `<canvas>` in `src/services/claudeService.js`.
- **Backend** — a single **Firebase Cloud Function** (`analyzeVideo`, Node 20, TypeScript) in `functions/src/index.ts`. It receives the frames/transcript, builds a multimodal message, and calls the **Anthropic Messages API**. This keeps the API key server-side rather than in the browser.
- **Hosting/routing** — `firebase.json` serves the built SPA and rewrites `POST /api/analyze` to the `analyzeVideo` function in `us-central1`; all other paths fall back to `index.html`.
- **Library persistence** — generated results are stored in the browser's `localStorage` under `1p-studio-library` (hook-frame thumbnail only, to stay within storage limits).

> **Note:** `src/app/tiktok-generator/page.tsx` is a Next.js-style route that also exists in the tree, but the active build is the Create React App entry (`src/App.js` via `react-scripts`).

## Local development

```bash
# 1. Install app dependencies
npm install

# 2. Install function dependencies
cd functions && npm install && cd ..

# 3. Run the app
npm start          # http://localhost:3000
```

For the `/api/analyze` endpoint to work locally, run the Firebase emulator for functions (`cd functions && npm run serve`) with an `ANTHROPIC_API_KEY` set, or deploy the function. The key is read from `process.env.ANTHROPIC_API_KEY` in the function — it is **never** shipped to the browser.

---

## Deployment

Deployment is automated via GitHub Actions (`.github/workflows/firebase-hosting-deploy.yml`) on every push to `main`:

1. Build the React app (`npm run build`).
2. Build and deploy the Cloud Functions (writes `ANTHROPIC_API_KEY` into `functions/.env`).
3. Deploy Hosting via the official Firebase hosting-deploy action.

Required GitHub secrets:

- `FIREBASE_SERVICE_ACCOUNT` — service account JSON for the `onepstudio-9a3ef` project
- `ANTHROPIC_API_KEY` — Anthropic API key used by the `analyzeVideo` function

Manual deploy equivalents:

```bash
npm run build
firebase deploy --only hosting,functions
```

---

## Security notes

- The Anthropic API key lives **only** on the server (Cloud Function env), so it is never exposed in browser network requests.
- Generated content and hook-frame thumbnails are stored in the user's browser `localStorage`; uploaded videos are processed in-memory and are not persisted server-side.
